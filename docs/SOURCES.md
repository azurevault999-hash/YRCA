# Sources and Evidence

Primary implementation evidence should come from current Moodle documentation and the actual Phase 1 development instance.

Reference categories:
- Moodle developer documentation for supported APIs, Web Services, plugin architecture and moodle-docker.
- Moodle LMS documentation for courses, quizzes, completion, feedback, competencies, roles and reporting.
- Maintained plugin documentation for certificate/verification requirements.

When an agent makes a capability decision, record the exact Moodle/plugin version and test evidence in the capability matrix. Do not treat an unverified assumption as a requirement.
