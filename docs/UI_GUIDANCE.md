# YRCCC UI Guidance

The supplied YRCCC 30-screen concept is a visual and journey anchor, not an instruction to duplicate the LMS.

Preserve:
- institutional authority and military/medical training context;
- clear next-action orientation;
- mobile-first touch-friendly layout;
- readable content in poor-connectivity environments;
- YRCCC terminology and visual identity.

Journey anchors:
1. Controlled entry/authentication.
2. Learner dashboard.
3. Learning Hub.
4. Video Library/player.
5. Assessments/results.
6. Skills/progress.
7. Feedback.
8. Completion.
9. Certificate.
10. Notifications/help/profile.
11. Faculty workspace.
12. Administrator/reporting workspace.

Implementation rule:
Identify the UI anchor, identify the Moodle capability, configure Moodle first, verify it, theme/present it, and custom-build only the demonstrated gap. Do not duplicate authoritative Moodle data merely to reproduce a screen.
